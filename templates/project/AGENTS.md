# IC Project Agent Guide

## SiliconBoot managed section begins

Read the existing project's root instructions first, then `.siliconboot/project.md`, `.siliconboot/ENVIRONMENT.md` and `.siliconboot/current/manifest.md`. Paths in this guide are relative to the existing project directory, not to this file. The current manifest is authoritative for paths and environment settings; rendered guidance can lag an interrupted activation. Reconcile any mismatch before running tools. Check the active validation record before claiming a tool or workflow is usable. Locate exact versions, providers, entrypoints, libraries, runtime settings, and official sources in the manifest and referenced receipts. Read the relevant recipe in the persistent [SiliconBoot guidance snapshot]([GUIDE_ABSOLUTE_PATH]/README.md), whose revision and digest are recorded in the manifest.

Use the generation's `tools` and `pdk` views to locate managed installations under [TOOLS_ABSOLUTE_PATH] and [PDKS_ABSOLUTE_PATH], and external Homebrew tools at their concrete paths in the manifest. Public executable symlinks are in [BIN_ABSOLUTE_PATH], the invoking user's `~/bin`. Do not create a workspace or project-root installation links. Preserve existing binary entries and record provider collisions. Detect the default login shell and maintain its single PATH section according to [shell setup]([GUIDE_ABSOLUTE_PATH]/docs/project-layout.md#default-shell-path). Apply documented per-tool interpreter, environment, and working-directory requirements. A library or plugin may have no executable. Do not invent entrypoints or generate launchers. For a long or reproducible run, follow the [run procedure]([GUIDE_ABSOLUTE_PATH]/prompts/run.md): resolve the generation once, register a lease, and use fixed generation paths throughout the full process tree.

Use uv by default for Python setup and maintenance. If missing, install and verify it first using the [uv recipe]([GUIDE_ABSOLUTE_PATH]/recipes/uv/README.md). Follow the [Python environment policy]([GUIDE_ABSOLUTE_PATH]/docs/python-environments.md): use isolated environments, compatible recorded interpreters, and the recorded `~/tools` root; preserve documented upstream-managed runtime exceptions. During design runs, use the fixed environment and avoid automatic package synchronization, lock updates or interpreter downloads. Changing an existing environment requires a separately verified candidate.

Setup creates only metadata and installation directories. During design work, keep user sources in `design` and `verification`, overrides in `config`, memory requests in `ip/memory/configs`, accepted macro records in `ip/memory/manifests`, and generated outputs in `runs`. Never write outputs into a shared tool or PDK. Preserve existing user files and instructions. A successful process exit alone proves neither design correctness nor timing, DRC, LVS, or memory acceptance.

For LibreLane AppImage, create a private `tmp` directory inside the admitted run and set `TMPDIR` to its canonical absolute path. Verify that the host allows FUSE mounts there; a writable installation store does not prove mount permission. Inspect mountpoint-policy denials before declaring FUSE unavailable. Follow [temporary mount guidance]([GUIDE_ABSOLUTE_PATH]/docs/project-layout.md#appimage-temporary-mounts), and remove the directory only after all processes and mounts finish.

When asked to upgrade, read the component's official sources, catalog, recipe, and receipts; follow the [upgrade procedure]([GUIDE_ABSOLUTE_PATH]/docs/upgrade.md). Resolve official latest inputs into a new frozen plan, build versioned installations, and verify affected workflows before atomic activation. Preserve the working generation on failure or latest incompatibility. Do not upgrade during ordinary design work or doctor checks.

For installation or upgrade on macOS, always check Homebrew first for each tool, including uv, and compare its current formula/cask with the latest official upstream release, native architecture and required features. Use a matching package under [the macOS policy]([GUIDE_ABSOLUTE_PATH]/docs/installation.md#macos-check-homebrew-first), retaining its external location as a standing exception to the managed tool root. Otherwise record why and use the best upstream-supported native binary, documented installer or source build of that same latest version. Protect retained generations, package dependencies and run leases. Exact restores keep their locked providers and inputs.

Follow the [validation procedure]([GUIDE_ABSOLUTE_PATH]/docs/validation.md) for inspection and the [cleanup procedure]([GUIDE_ABSOLUTE_PATH]/docs/cleanup.md) for owned temporary artifacts. Preserve runtime sources, licenses, retained generations, and shared installations. Garbage collection is a separate explicit operation. Record exact inputs, genuine exit statuses, evidence, failures, and limitations in English Markdown. Use no sudo during setup or maintenance under these prompts. Record privileged dependency blockers and continue independent work; separate administrator action requires an explicit request and host approval. Never store passwords.

# Run a design task

> Find the local SiliconBoot clone and the existing project directory from context, defaulting to the clone. Read the applicable AGENTS.md and .siliconboot/AGENTS.md. Perform `<DESIGN_TASK>` in that existing directory using `<COMPONENT_OR_WORKFLOW>` from the selected generation; do not create a workspace. Acquire the host-change, project and registry locks in that order to admit the run and record its lease, then release those short admission locks. Resolve that generation to its persistent absolute path during admission and keep its tools, PDKs, interpreter and runtime settings fixed for the whole run. Place the concrete generation's bin first in the run's process PATH instead of relying on mutable ~/bin links. Read the relevant recipe and existing validation evidence. Write generated artifacts, reports and logs into a new directory under runs/. Preserve user sources and shared installations. Record input hashes, versions, exact invocation and working directory, actual exit status, parsed engineering checks and output locations. Release the lease only when all associated processes finish. Do not use sudo or upgrade the environment during the task.

An exit status alone cannot establish simulation correctness, timing closure, DRC, LVS, or memory validity. See [validation](../docs/validation.md).

For Python, use the recorded entrypoint or fixed interpreter. If upstream requires uv to launch the workflow, follow the verified settings that disable synchronization, lock updates and downloads. Missing dependencies require a separate maintenance operation; see [Python environments](../docs/python-environments.md).

For LibreLane AppImage, create this run's private `runs/<run-id>/tmp` inside the existing project, verify its canonical path against the host FUSE mount policy, and scope `TMPDIR` to that path. Keep it until all processes and mounts finish; follow [temporary mount guidance](../docs/project-layout.md#appimage-temporary-mounts). Do not infer mount permission from a writable installation directory.

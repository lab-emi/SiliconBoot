# Inspect and plan

> Find the local SiliconBoot clone and plan setup of an IC design project in its workspace/ folder. Use `<ABSOLUTE_INSTALL_PATH>` as the installation root for all catalogued IC design tools, SRAM compilers and PDKs. Follow AGENTS.md and docs/bootstrap.md. Produce a proposed native installation plan without installing components, changing system packages, or activating a generation. Inspect host architecture, resources, existing installations and workspace conflicts. Plan to use uv for Python environments; check whether it exists and include its official installation before Python setup if missing. Resolve official latest versions, dependencies, coupled groups, native providers and required permissions. Show all requested items, including unknown versions and unsupported or unresolved sources. Identify expected validation workflows and any limitations of the latest combination. Save the proposed plan in the workspace only if a safe, nonconflicting record location exists; otherwise present it in the response.

A reviewed plan freezes source selections for its operation. It is not proof that the selections build or work together.
